PC Building Guide
Step Component / Action What to do
1 CPU Install the CPU into the motherboard socket. Align the triangle marker correctly.
2 RAM Insert RAM sticks into the recommended motherboard slots until they click.
3 M.2 SSD Install the SSD into the M.2 slot and secure it with a screw.
4 CPU Cooler Install the CPU cooler and connect its fan to CPU_FAN.
5 Motherboard Install the motherboard into the PC case using standoffs.
6 Power Supply (PSU) Install the PSU into the case.
7 GPU Insert the graphics card into the PCIe x16 slot and secure it.
8 Connect Cables Connect motherboard power, CPU power, GPU power, SATA, and case cables.
9 Case Fans Install fans and connect them to fan headers or a fan hub.
10 First Boot Connect monitor, keyboard, and mouse. Turn on the PC and enter BIOS.
11 Install OS Install Windows or Linux using a bootable USB.
12 Install Drivers Install chipset, GPU, network, and audio drivers.
